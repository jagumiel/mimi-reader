# Project identity, credits and upstream history

## Current independent continuation

The current repository is [jagumiel/mimi-reader](https://github.com/jagumiel/mimi-reader),
maintained by [@jagumiel](https://github.com/jagumiel). It is a free, independent
continuation, not a release endorsed by the original author or previous forks.
There is no separate paid edition. The planned release is 8.0, but the build
remains 7.0.1 / versionCode 230 until release preparation is agreed.

Mimi is no longer available on Google Play. The original `mimireader.com`
website is not operational; this does not establish when it closed or whether
the domain registration still exists. Do not advertise either as a current
distribution or support destination.

As checked on 23 October 2026, the current repository has neither Issues nor
Discussions enabled. More Info opens the repository, not an unavailable issue
tracker, an invented contact address, or the original maintainer's email.
It sends no feedback email and collects/attaches no diagnostic report. All
project, license and credit links are explicit browser navigation, with the
existing missing/blocked-handler error handling. No support response is promised.
